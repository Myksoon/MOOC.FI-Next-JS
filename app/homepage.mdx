# Blog app

A place to collect and share **interesting blog posts**. Built for the
[Full Stack Open: Next.js](https://fullstackopen.com/) course.

## What you can do

- Browse the [blogs](/blogs), sorted by likes, and search them by title
- See who added what on the [users](/users) page
- [Register](/register) and [log in](/login) to add blogs of your own
- Keep a reading list of blogs you want to read later

## Built with

- **Frontend:** Next.js App Router and React
- **Database:** Postgres on Neon, queried with Drizzle ORM
- **Auth:** NextAuth (Auth.js) with username and password
- **Styling:** Tailwind CSS
